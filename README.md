# موقع استمارة EMIS — GitHub Pages

موقع عربي RTL لاستكمال استمارة بيانات الطالب/التلميذ، مع معاينة A4 وإدارة ملفات Excel.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع `index.html` إلى المجلد الرئيسي للمستودع.
3. افتح **Settings → Pages**.
4. اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)` ثم **Save**.
5. انتظر اكتمال النشر وافتح الرابط الذي يظهر في صفحة Pages.

## الميزات
- استمارة إدخال عربية مع معاينة مباشرة للورقة الرسمية A4.
- تنزيل PDF مباشر، مع خيار الطباعة التقليدي.
- استيراد Excel بصيغ XLSX وXLS وCSV، مع استيراد عدة طلاب دفعة واحدة.
- سجل محلي للطلاب المستوردين: فتح سجل في الاستمارة، حذفه، أو تصدير السجل كاملاً.
- تنزيل Excel للطالب الحالي، ولكل الطلاب، وقالب Excel فارغ.
- الاحتفاظ بخصائص المشروع الأصلية: الحفظ التلقائي للمسودة محلياً، إعداد Google Apps Script، وواتساب، وبيانات CSV.

## قالب Excel
من زر **سجل الطلاب** اختر **تحميل قالب Excel**. املأ صفاً لكل طالب مع إبقاء صف العناوين كما هو، ثم استورد الملف من زر **استيراد Excel**.

## ملاحظات مهمة عن حفظ البيانات
- مسودات الاستمارة وسجل الطلاب المستوردين تُخزّن في `localStorage` داخل المتصفح والجهاز الحالي فقط؛ لا تنتقل تلقائياً إلى جهاز آخر.
- للمزامنة السحابية استخدم إعداد Google Apps Script الموجود في الموقع، أو اربط الموقع بخدمة قاعدة بيانات لاحقاً.
- ملفات Excel وPDF تُنشأ داخل المتصفح ولا تُرفع تلقائياً إلى GitHub.
- مكتبتا Excel وPDF تُحمّلان من CDN؛ لذلك تحتاج ميزات الاستيراد والتصدير وPDF المباشر إلى اتصال بالإنترنت. إن لم تتوفر مكتبة PDF استخدم **طباعة / PDF**.

## إعداد Google Sheets
زر **إعدادات الربط** يحتفظ بخيار Google Apps Script ورقم واتساب. لا تضع أسراراً أو كلمات مرور داخل ملف HTML عام.
